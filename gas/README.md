# 강동어울림복지관 홍보 통합실적 관리 앱 - GAS 백엔드 설치 가이드

본 가이드는 Google Apps Script(GAS) 및 Google Sheets를 활용하여 게시판 자동 스크래핑 backend 및 Web App JSON API를 세팅하는 단계별 매뉴얼입니다.

---

## 1. 구글 스프레드시트 및 스크립트 생성

1. [Google Drive](https://drive.google.com)에 접속하여 새 **Google 스프레드시트**를 생성합니다.
   - 문서 제목 예시: `[강동어울림복지관] 홍보 통합실적 수집 DB`
2. 상단 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
3. 스크립트 에디터 내 `Code.gs` 기본 내용을 모두 지우고, 본 저장소의 [Code.gs](Code.gs) 파일의 전체 코드를 복사하여 붙여넣습니다.
4. Ctrl + S (저장)를 누릅니다.

---

## 2. 초기화 및 스크래핑 테스트

1. 상단 함수 선택 드롭다운에서 `initSheets`를 선택하고 **[실행]** 버튼을 클릭합니다.
   - 최초 실행 시 권한 승인 창이 뜨면 계정을 선택하고 **[고급] > [안전하지 않은 페이지로 이동] > [허용]**을 클릭합니다.
   - 실행 완료 후 스프레드시트에 `수집이력`, `일별집계`, `config` 3개 시트가 자동 세팅되었는지 확인합니다.
2. 함수 선택 드롭다운에서 `runScraper`를 선택하고 **[실행]** 버튼을 클릭합니다.
   - 복지관 홈페이지 게시판을 수집하여 `수집이력` 및 `일별집계`에 데이터가 적재되는지 확인합니다.

---

## 3. Web App 배포 (API URL 생성)

1. 스크립트 에디터 우측 상단의 **[배포] > [새 배포]** 버튼을 클릭합니다.
2. 톱니바퀴 아이콘을 누르고 **[웹 앱]**을 선택합니다.
3. 배포 설정 항목을 다음과 같이 입력합니다:
   - **설명**: `홍보통합실적 API v1.0`
   - **실행할 사용자**: `나 (자신의 이메일)`
   - **액세스 권한이 있는 사용자**: `모든 사용자 (Anyone)` 또는 `강동어울림복지관 도메인의 모든 사용자`
4. **[배포]** 버튼을 클릭합니다.
5. 생성된 **웹 앱 URL** (예: `https://script.google.com/macros/s/.../exec`)을 복사합니다.

---

## 4. 15분 주기 자동 스크래핑 트리거 설정

1. 스크립트 에디터 함수 선택 드롭다운에서 `createTrigger`를 선택하고 **[실행]**을 클릭합니다.
2. 이후 15분 간격으로 `runScraper` 함수가 자동 실행되어 신규 게시글을 감지하고 일별 실적을 갱신합니다.

---
